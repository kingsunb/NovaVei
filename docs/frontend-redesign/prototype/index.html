强大特性

个人也能拥有企业级的 LLM 网关能力

多渠道聚合

接入多个 LLM 供应商，统一管理、统一计费、统一监控。

三态熔断

CLOSED / OPEN / HALF-OPEN 状态机，上游故障自动转移。

敏感脱敏

流式脱敏规则引擎，传输中实时擦除敏感信息，不改业务代码。

单渠道多 Key

多凭据轮询、401/403 自动冷却换 Key、按账号注入独立代理。

全链路可视化

请求发起后即可实时查看完整链路与每次尝试轨迹。

协议互转

OpenAI Chat / Responses / Anthropic 三种格式无缝互转。

轻量单文件

单个二进制即可运行，无需额外运行时依赖，开箱即用。

多数据库

支持 SQLite、MySQL、PostgreSQL，按规模自由选择。

工作原理

三步即可开始

1

添加渠道

填入供应商 API Key 与地址，配置模型映射。

2

创建密钥

生成 NovaVei 访问令牌，分发给你的客户端。

3

开始调用

把客户端 baseURL 指向 NovaVei，即刻聚合所有模型。

快速开始

Docker 一行启动，30 秒拥有自己的 LLM 网关。

bash 
docker run -d -p 8000:8000 \
  -v novavei-data:/data \
  --name novavei \
  ghcr.io/kingsunb/novavei-api:latest

或 下载二进制 · 源码构建
